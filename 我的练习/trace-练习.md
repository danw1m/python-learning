# 逐行走查练习（trace）

> 用法：不许运行代码。拿笔在表里一格一格填，填完再跑一遍对答案。
> 这是「读代码」和「写代码」之间的桥。走查熟了，写的时候脑子里会自动播这个表。

---

## 第1题

```python
total = 0
for i in range(1, 4):
    total += i
    print(i, total)
```

| 轮次 | i | total 执行后 |
|---|---|---|
| 1 | | |
| 2 | | |
| 3 | | |

## 第2题

```python
count = 0
for i in range(1, 6):
    if i % 2 == 0:
        count += 1
print(count)
```

## 第4题（带 continue）

## 做完之后

对答案，把填错的格子圈出来，记一句「我漏了哪一步」。

然后把这几道代码自己敲一遍，跑一下，看输出的每一行能不能对上表里的一行。
