第一部分　知识点总结

Day1　环境与第一个程序

  • PyCharm 是什么：写代码的地方，本身不能跑代码。真正执行的是 Python 解释器。
  • 三件套：编辑器写代码、解释器执行、终端看结果。
  • print()：把括号里的东西显示出来。
  • input()：显示提示，停住等你打字，回车后继续。
  • 变量赋值：name = input("你叫什么？")，右边整体跑完，结果装进左边的盒子。
  • for 循环：for i in range(3): 下面缩进的部分重复三遍。
  • 注释：# 开头，电脑不看这行。
  • 缩进：属于循环、判断的代码前面空四格，少了多了都算错。

Day2　第一个 Python 程序

  • 字符串用单引号或双引号都行，'abc' 和 "abc" 一样。
  • Python 语句不用分号结尾，换行就表示一句结束。
  • 单行注释：#，多行注释：三个引号开头、三个引号结尾。
  • 标点必须是英文输入法下的。写成中文，报 SyntaxError: invalid character '（' (U+FF08)。

Day3　变量和类型

  • 变量：一块保存数据的内存空间，值可读可改。
  • 四种常用类型：int 整数、float 小数、str 文字、bool 真假（只有 True / False）。
  • type(变量) 查类型，打出来是 <class 'int'> 这种，意思就是「它属于 int 这一类」。
  • 进制写法：0b 二进制、0o 八进制、0x 十六进制。
    例：0b1010 = 10，0o17 = 15，0x1f = 1×16+15 = 31。
  • 命名规则（不遵守就报错）：
    • 只能由字母、数字、下划线组成，数字不能开头
    • 大小写敏感，Age 和 age 是两个变量
    • 不能跟关键字、内置名重名：if、for、True、int、print、input 都不行
  • 命名惯例：用小写字母，多个单词用下划线连，my_age。单个下划线开头（_age）是合法的。
  • 类型转换：int() 转整数、float() 转小数、str() 转文字、bool() 转真假、chr() 编号转字符、ord() 字符转编号。
  • int('101', base=2) 表示把 '101' 当二进制看，等于 5。

Day4　运算符

运算符意思例子结果
+ - * /加减乘除321 / 1226.75（除法一定出小数）
//整除，只留整数部分321 // 1226
%取余，只留余数321 % 129
**乘方2 ** 101024
  • 优先级：** 高于 * / // %，高于 + -。括号优先。
    例：(2 + 3) * 5 ** 2 先算 5²=25，再 5×25=125。
  • 复合赋值：a += 5 等于 a = a + 5；a *= 2 等于 a = a * 2。
  • 海象运算符 :=：边赋值边出值，print((a := 10)) 打印 10，a 也变成 10。用得少，知道就行。
  • 比较运算符：== != < > <= >=，结果是 True 或 False。注意比较用两个等号。
  • 逻辑运算符：and（都真才真）、or（一个真就真）、not（取反）。
  • 值相等 ≠ 类型相同：1 == 1.0 是 True，0 == False 是 True，但 '0' == 0 是 False。
  • f-string：f'面积:{area:.2f}'，:.2f 保留两位小数，:.1f 一位。
    f'{y = }' 会打出「y = 值」，这是 3.8 加的调试写法，只在调试时用。
  • import math 之后可以用 math.pi 拿圆周率。

Day5　分支结构

  • 基本形状：if 条件: 满足走这里；elif 条件: 前面不满足再看这里；else: 全都不满足走这里。
  • 三条规矩：冒号是英文冒号、下面内容缩进四格、同一层代码缩进必须一样。
  • 只有一条路会被执行，其余跳过。
  • 链式比较：18.5 <= bmi < 24，Python 支持这种写法，不用拆成两个条件再 and。
  • elif 的顺序很重要：判断成绩要从高往低写，反过来全落到第一个分支。
  • match-case（3.10 以后）： 
    match 变量:
    case 1: print("星期一")
    case 400 | 401 | 404: print("请求有问题")   # 竖线表示"或者"
    case _: print("输入有误")                  # 下划线通配，放最后
  • 嵌套 vs 扁平：能扁平就别嵌套。Python 之禅里那句「Flat is better than nested」，嵌套多了没法读。

Day6　循环结构

  • 知道几次用 for，不知道几次用 while。
  • range 四种写法：
    写法产生
    range(5)0 1 2 3 4（取不到 5）
    range(1, 5)1 2 3 4（左闭右开）
    range(1, 10, 3)1 4 7（步长 3）
    range(100, 0, -50)100 50（负步长倒着数）
  • 累加器模式（高频套路）： 
    total = 0
for i in range(1, 101):
    total += i
print(total)      # 5050
  • while 要点：循环变量要在循环体里自己变大，忘了就是死循环。 
    i = 1
while i <= 100:
    total += i
    i += 1        # 这一行缺了就是死循环
  • break：立刻结束整个循环，后面的代码一行都不执行。
  • continue：这一轮剩下的跳过，直接进入下一轮。continue 只能待在循环里，单独写报 SyntaxError: 'continue' not properly in loop。
  • 嵌套循环：外层管行，内层管列。九九表就是这个结构。
  • 随机数：import random，random.randrange(1, 101) 出 1 到 100 的整数。
  • 素数判断：从 2 试到它的平方根，能整除就 break，用一个布尔变量记结果。
  • 最大公约数：从大到小试，第一个能同时整除两个数的就是答案，找到就 break。

第二部分　错题详解（40 条）

编号与错题本一致，按时间排。每条：什么错 → 为什么 → 怎么改。

10-26　Day2、Day3

1. 把 int、float、str、bool 当变量名命名

报错　TypeError: 'int' object is not callable

为什么：这四个是 Python 自带的函数。你写 int = 25，等于把它抢过来变成数字，之后再调 int('123') 就叫不动了。

正解　变量名换成 my_int、my_float 这种，别跟内置名撞。

记住：内置名、关键字，一个都不能拿来当变量名。

2. 0x1f 以为等于 16进制

为什么：0x 是十六进制。1 在十六位，f 是 15，所以 1×16+15 = 31。

正解　看到 0b、0o、0x 先确认进制，再按位权展开。0b1010 = 10，0o17 = 15，0x1f = 31。

3. int('101', base=2) 猜 4，实际 5进制

为什么：二进制 101 是 1×4 + 0×2 + 1 = 5，不是把三个数字当 1、0、1 读。

正解　base 参数表示「把这个字符串按几进制理解」，从右往左每位的权重是 1、2、4、8……

4. hallo 拼成了错的样子习惯

为什么：拼写错误程序不报错，安安静静把错的打出来，最难发现。

正解　写完读一遍输出，别只看「有没有报错」。

5. 转换了但没 print习惯

为什么：int('123') 算出来了，但没让它显示，运行窗口就是空的。

正解　转换和打印是两件事，要看见就得 print()。

6. 中文括号标点

报错　SyntaxError: invalid character '（' (U+FF08)

为什么：输入法还在中文状态，括号、引号、冒号全成了全角字符，Python 不认。

正解　看到 invalid character 加 U+ 编号，第一反应就是中文标点。写代码前切英文。

10-27　复习01

7. 把 input() 直接塞进 print输入

错法：print(input("请输入数字"))，两个输入各打各的，中间没有任何关系，做不了加法。

为什么：input 拿回来就打印了，没有装进任何变量，也就没法参与运算。

正解　三行：x = int(input("第一个数："))、y = int(input("第二个数："))、print(x + y)。

8. 知道要转换，不知道怎么写进变量输入

模板　变量名 = int(input("提示语"))　等号右边整体跑完，结果才装进左边。

记住：这个形状以后要写几百遍，背下来。

9. 文字加数字类型

报错　TypeError: can only concatenate str (not "int") to str

为什么：+ 两边都是文字才叫拼接，混进数字就崩。

正解　先算进变量，用 str() 转成文字，再拼。拼接里不要塞运算。
next_age = age + 1　print("明年" + str(next_age) + "岁")

10. float 拼成 floes拼写

为什么：拼错不报错，但答案算错。

正解　四个类型名背死：int、float、str、bool。

11. 以为循环输出在一行循环

为什么：print 每次都换行，for i in range(3): print(i) 出来是 0、1、2 三行。

正解　想不换行用 print(i, end=' ') 或 end='\t'。

12. 改错题改错了内容习惯

为什么：根因是缩进，不是 print 里的字。

正解　只补缩进，字别动。改错先问「哪条规矩破了」。

13. 变量名判断错两处命名

为什么：_age 合法（单个下划线开头可以）；my age 不合法（中间不能有空格）。

正解　想分词就用下划线：my_age。

14. 打印时把内容写死习惯

为什么：建了 name、age 变量，打印却写死「我叫老大，今年20岁」，变量建了等于没建。

正解　用变量拼：print("我叫" + name + "，今年" + age + "岁")。

10-28　复习02、Day4 运算符

15. 循环里打什么，看成循环变量循环

错法：for i in range(2): print("循环")，答案写成 0、1。

为什么：循环只负责重复次数，打什么由 print 里写的东西决定。

正解　实际打两行「循环」。想打 0、1 得写 print(i)。

16. 又打成中文括号标点

为什么：第二次犯。逻辑没错，标点错，一样跑不起来。

正解　写代码前先看输入法。这个错一旦养成，一天能犯十次。

17. PyCharm 自动补全误点出垃圾 import习惯

为什么：文件顶部多了 from ftplib import parse150，不影响运行但完全没用，看着像懂行，其实是不认识的东西。

正解　自己不认识的 import，直接删。补全弹窗别乱按 Tab。

18. 答案看串行习惯

为什么：321 // 12 是 26，321 % 12 是 9，两道答案写反了。

正解　题多的时候写完对一遍行号。

19. 没搞清 ** 的优先级运算符

错法：(2 + 3) * 5 ** 2 答 625，实际 125。

为什么：** 比 * 先算。先 5² = 25，再 5×25 = 125。

625 怎么来的：把它当成 ((2+3)*5)**2 了，多套一层括号。

20. 把「值相等」当成「类型相同」运算符

错法：1 == 1.0 答 False，0 == False 答不相等。

为什么：== 比的是值，不看类型。1 和 1.0 数值相同，False 在数字里就当 0 用。

正解　== 看值，type() 看类型。但 '0' == 0 是 False——字符串和数字不是一回事。

21. 布尔值大小写拼写

为什么：答案写 true、false，Python 打出来是 True、False，首字母必须大写。

正解　True、False 当关键字看，大小写错了就不是那个东西。

22. 该用 float 的地方用了 int类型

为什么：华氏温度、圆的半径都可能带小数，int 会把小数部分直接砍掉，98.6 变 98。

正解　可能带小数的量一律 float。要保留两位小数写 f'{area:.2f}'，光转换不够。

23. f-string 外面又包 str()习惯

为什么：str(f'{x:.2f}')，f-string 出来本来就是字符串，再转一次白转。

正解　直接 print(f'周长:{x:.2f}')。

24. 复制粘贴忘改字习惯

为什么：面积那行打印成了「周长：78.54」，逻辑对、标签错。

正解　复制代码后，把变量名和文字一起过一遍。

10-29（28 号深夜）　Day5 分支

25. if 里用了单等号语法

报错　SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?

为什么：= 是赋值，== 才是比较。if、elif、while 后面一律两个等号。

正解　Python 连提示都写在报错里了，看到 "Maybe you meant '=='" 就改两个等号。

26. 语法错误会挡住整个文件调试

为什么：只要有一处语法错，整个文件一行都不跑，后面的运行时错误全被盖住。

正解　改完一处立刻再跑一遍，一层层往下清，别一次改五处。

27. 变量名前后不一致命名

报错　NameError: name 'zc' is not defined

为什么：上面定义的是 zs，下面用了 zc。

正解　敲完顺手看一眼上下行变量名对不对。NameError 八成就是拼错或没定义。

28. 把半周长当周长打逻辑

错法：print("周长:" + str(s))，s 是半周长。边长 3、4、5 应打 12，实际打了 6。

正解　中间变量叫什么，打印前心里过一遍。周长是 a + b + c，半周长才是除以 2。

29. float() 外面又包 f-string类型

错法：float(f'{tz/(sg/100)**2}')，先变文字再转回数字，绕一圈还可能出错。

正解　直接 tz / (sg / 100) ** 2，除法出来的本来就是小数。

30. 变量名拼错 BMI命名

为什么：写成 BIM。不报错，但自己以后看不懂。

正解　缩写也别拼错，B-M-I 顺序别乱。

31. 判断题漏答习惯

为什么：只写「大于3」，漏了后面那行「结束」。

正解　print("结束") 没缩进，不在 if 里，一定会执行。

32. 没看出 if x = 5 的错语法

为什么：就是第 25 条那个单等号。

正解　看到 if 后面有单个等号，直接判错。

33. 改错去改内容，不改根因习惯

为什么：根因是缩进，却加了个 else 把题目要求也改了。

正解　改错先找「哪条规矩破了」，只修那一条。

10-29　Day6 循环

34. break 和 continue 理解反了循环

错法　1-5 答 3（实际打 0、1、2）；1-6 答 0、2、4（实际打 1、3）

为什么：以为 break 是「打完这一轮再停」，continue 是「满足条件才执行」。

正解　break 是掀桌子走人，整个循环立刻结束；continue 是这盘菜不吃，下一盘继续。

对照：for i in range(10): if i == 3: break; print(i) → 0 1 2。
for i in range(5): if i % 2 == 0: continue; print(i) → 1 3。

35. 改错时把正确的东西也删了习惯

为什么：死循环那题只加了 i += 1，把 print(i) 删了，最后只打一个 6。

正解　循环体里两行：先 print(i)，再 i += 1。改错只动错的地方。

36. 说 continue 单独写「可能报错」语法

报错　SyntaxError: 'continue' not properly in loop

为什么：不是可能，是必定。continue 只能待在循环里。

正解　break 和 continue 都是循环专用，放外面一律语法错误。

37. 最大公约数，循环变量没参与判断逻辑

错法：写了 for i in range(m, 0, -1)，条件却是 m % j == 0 and j % m == 0，i 一次都没用到。

为什么：循环变量不进条件，这个循环等于空转。而且 m % j 表示「m 能被 j 整除」，意思也反了。

正解　条件用 i：if m % i == 0 and j % i == 0:

38. 找到答案忘了 break循环

为什么：条件成立后没 break，循环继续往下试，会打出一堆结果。

正解　「找到就走」的场景，print 后面紧跟 break。

39. 打印用错变量逻辑

错法：print(f'{m}是最大公因数')，输入 12 和 18 打出 12。

为什么：m 是最初输入的数，从头没变过。答案在循环变量 i 身上。

正解　print(f'{i}是最大公因数')，12 和 18 出 6。

40. 变量名随手起命名

为什么：猜数字里用了 da、op、CS。能跑，但过两天自己看不懂。

正解　answer、guess、count 这种，见名知意。面试官也看这个。

3. 六条铁律

  1. 代码里的标点，永远是英文的。
  2. = 是装进去，== 是问相等。
  3. 属于 if / for / while 的行，缩进四格。
  4. 知道循环几次用 for，不知道用 while，while 里别忘了让变量变。
  5. 可能带小数就用 float，输入永远先是字符串。
  6. 变量名写清楚，别用 da、op、aaa 这种。
